Memulai

Pengantar

Localix adalah aplikasi pengelola server lokal untuk Windows. Apache, PHP, MySQL, phpMyAdmin, dan Composer sudah disertakan, jadi Anda bisa menjalankan project web lokal tanpa memasang atau mengonfigurasi apa pun secara manual.

Versi saat ini: 0.2.0. Unduh dari GitHub Releases. Lihat yang baru di Catatan Rilis.

Yang disertakan

  • Apache 2.4: web server (port bawaan 80)
  • PHP 8.4: runtime PHP bawaan. PHP 8.2, 8.3, dan 8.5 bisa dipasang dari halaman PHP
  • MySQL 9.6: database server (port bawaan 3306)
  • phpMyAdmin 5.2: pengelola database berbasis web
  • Composer 2.9: dependency manager PHP
Memulai

Instalasi

Tersedia dua format rilis:

Installer

Wizard instalasi Windows biasa. Anda bisa memilih folder instalasinya.

localix.setup.exe

Portable

Satu file exe tanpa instalasi. Data disimpan di folder localix-data di sebelahnya.

localix.0.2.0.x64.exe

Langkah

  1. Buka rilis terbaru di GitHub.
  2. Unduh localix.setup.exe atau versi portable.
  3. (Opsional) Cocokkan checksum dengan SHA256SUMS.txt.
  4. Jalankan installer, atau buka file portable-nya.
Windows SmartScreen bisa menampilkan peringatan karena aplikasi belum ditandatangani. Lihat SmartScreen.
Memulai

Menjalankan pertama kali

  1. Buka Localix. Dasbor tampil dengan Apache dan MySQL dalam keadaan berhenti.
  2. Klik Start All untuk menjalankan keduanya.
  3. Klik Localhost atau buka http://localhost di browser. Halaman sambutan Localix menandakan server sudah jalan.
  4. Klik phpMyAdmin atau buka http://localhost/phpmyadmin untuk mengelola database.
  5. Klik Folder www dan taruh project Anda di sana.
Login MySQL bawaan: username root, password kosong.

Struktur folder

Setelah instalasi, folder Localix berisi seperti ini. Versi portable memakai folder yang sama di dalam localix-data/.

Folder instalasi Localix
localix/
├── localix.exe          # Aplikasi utama
├── resources/runtime/   # Runtime bawaan (hanya-baca)
│   ├── apache/          # Apache 2.4
│   ├── php/8.4/         # PHP 8.4
│   ├── mysql/           # MySQL 9.6
│   ├── phpmyadmin/      # phpMyAdmin
│   └── composer/        # Composer
├── www/                 # ← Taruh project Anda di sini
├── runtimes/            # PHP / phpMyAdmin yang dipasang dari halaman PHP
├── config/
│   ├── httpd.conf       # Konfigurasi Apache
│   ├── php.ini          # Konfigurasi PHP (diatur dari halaman PHP)
│   ├── my.ini           # Konfigurasi MySQL
│   └── vhosts.conf      # Konfigurasi virtual host (dibuat otomatis)
├── data/
│   └── mysql/           # Data database MySQL
└── logs/                # Log Localix, Apache, MySQL, dan PHP
Fitur

Projects

Setiap folder di dalam www/ dianggap sebagai project. Localix memindai folder ini selama aplikasi berjalan dan menampilkannya di halaman Projects, lengkap dengan URL dan foldernya.

Pola URL
www/my-project   →  http://localhost/my-project/
www/portfolio    →  http://localhost/portfolio/
Project Laravel yang punya folder public/ otomatis dilayani dari public/. Nama folder phpmyadmin dicadangkan dan diabaikan oleh pemindai.
Fitur

Virtual Host

Virtual Host memberi setiap project domain lokal sendiri, misalnya my-project.locx, sebagai ganti localhost/my-project.

  1. Buka halaman Projects.
  2. Aktifkan Virtual host.
  3. Atur akhiran domain (bawaan .locx) lalu klik Simpan.
  4. Klik Copy hosts entry (atau Buka hosts file) dan tempel entrinya ke file hosts Windows.
  5. Jika domain project baru belum muncul, klik Regenerate.
C:\Windows\System32\drivers\etc\hosts
127.0.0.1  my-project.locx
127.0.0.1  portfolio.locx
Mengedit file hosts membutuhkan hak Administrator. Buka Notepad dengan Run as administrator sebelum menempelkan entri.
Fitur

Laravel

Composer sudah disertakan, jadi Anda bisa membuat project Laravel tanpa memasang PHP atau Composer di Windows.

  1. Di halaman Projects, klik + Laravel.
  2. Isi Nama project Laravel dan pilih Lokasi dengan Browse.
  3. Klik Buat project. Localix menjalankan composer create-project laravel/laravel memakai PHP dan Composer bawaan.
  4. Setelah selesai, project muncul di halaman Projects (dengan domain .locx jika Virtual Host aktif).

Artisan dan Composer di terminal

Aktifkan PHP di terminal, buka terminal baru, lalu jalankan perintah dari folder project seperti biasa:

Terminal
cd C:\localix\www\my-store
php artisan migrate
composer require laravel/breeze --dev
Pengaturan database bawaan Laravel di .env cocok dengan Localix: DB_HOST=127.0.0.1, DB_PORT=3306, DB_USERNAME=root, DB_PASSWORD= (kosong).
Fitur

PHP

Semua pengaturan PHP ada di halaman PHP, yang punya tiga tab.

Versi (Versi)

Pasang, perbarui, aktifkan, atau hapus PHP 8.2 sampai 8.5. File diunduh dari situs resmi PHP dan dicek SHA-256 sebelum dipakai. Klik Periksa update untuk melihat versi terbaru. Versi aktif juga bisa diganti dari dasbor atau menu tray. Jika Apache gagal start setelah ganti versi, versi sebelumnya dipulihkan otomatis.

Extensions

Centang extension yang ingin diaktifkan. Yang aktif secara bawaan:

  • pdo_mysql, mysqli, pdo_sqlite, sqlite3 untuk database
  • openssl, curl untuk koneksi aman
  • gd, mbstring, zip, fileinfo, intl untuk framework modern

mysqli, mbstring, openssl, dan pdo_sqlite selalu aktif dan tidak bisa dimatikan.

Pengaturan (Pengaturan)

Atur memory limit, ukuran upload, max execution time, timezone, tampilan error di browser, dan OPcache, lalu klik Simpan & terapkan. Localix menguji config/php.ini yang baru sebelum menerapkannya. Baris tambahan bisa ditulis di Custom directives. Gunakan Lihat php.ini untuk melihat hasilnya atau Kembalikan default untuk mengulang dari awal.

PHP di terminal

Di tab Pengaturan, aktifkan Pakai PHP Localix di terminal. Localix menambahkan PHP aktif dan Composer ke PATH Windows (khusus user Anda), sehingga php, php artisan, dan composer di terminal memakai versi dan pengaturan php.ini yang sama dengan Localix. Saat Anda ganti versi PHP, PATH ikut diperbarui.

Buka terminal baru (atau restart VS Code) setelah mengaktifkannya. Jika ada PHP lain di PATH sistem, PHP itu dipakai lebih dulu dan Localix akan menampilkan peringatan. Matikan sakelar ini untuk mengembalikan PATH seperti semula.
Fitur

phpMyAdmin

phpMyAdmin sudah terpasang. Buka lewat tombol phpMyAdmin di dasbor atau di http://localhost/phpmyadmin, lalu login dengan username root dan password kosong.

Demi keamanan, phpMyAdmin hanya bisa dibuka dari komputer Anda sendiri (localhost / 127.0.0.1). Versi yang lebih baru bisa dipasang dari tab Versi di halaman PHP.

Fitur

Logs

Halaman Logs menampilkan log Localix, Apache Error, Apache Access, MySQL, dan PHP Error. Gunakan Refresh untuk memuat ulang, Clear Log untuk mengosongkan, dan Open Logs Folder untuk membuka folder logs/.

Konfigurasi

Settings

  • Jalankan saat Windows start: Localix berjalan di latar belakang (system tray) saat Windows menyala.
  • Start layanan saat dibuka: Apache dan MySQL langsung berjalan saat Localix dibuka, dan browser bisa dibuka otomatis setelah server siap.
  • Tema: terang, gelap, atau ikuti Windows.
  • Port: ubah port Apache (bawaan 80) dan MySQL (bawaan 3306).
  • Perawatan: Check Ports, perbaiki konfigurasi phpMyAdmin, dan inisialisasi ulang data MySQL (data lama di-backup dulu).
Konfigurasi

Apache

Konfigurasi Apache ada di config/httpd.conf. Anda bisa mengeditnya untuk mengaktifkan modul atau mengatur akses folder.

Konfigurasi yang salah bisa membuat Apache gagal start. Jika itu terjadi, kembalikan perubahan dan cek log Apache Error di halaman Logs.
Konfigurasi

MySQL

MySQL dikonfigurasi lewat config/my.ini, dan datanya disimpan di data/mysql/. Port bawaannya 3306; ubah di Settings jika port itu sudah dipakai database lain.

Untuk backup, hentikan MySQL lalu salin folder data/mysql/, atau ekspor database dari phpMyAdmin.
Pemecahan masalah

Konflik port

Jika Apache gagal start, biasanya port 80 sedang dipakai aplikasi lain (IIS, Skype, XAMPP, dan sebagainya). Klik Check Ports di Settings untuk melihat port mana yang terpakai.

Opsi A: tutup aplikasi lain

Hentikan aplikasi yang memakai port tersebut, lalu klik Start All lagi.

Opsi B: ganti port Apache

  1. Buka Settings.
  2. Ganti port Apache ke port yang kosong, misalnya 8080.
  3. Restart Apache, lalu buka http://localhost:8080.

Opsi C: jalankan sebagai Administrator

Klik kanan Localix lalu pilih Run as administrator. Ini bisa membantu jika Windows menolak akses ke port 80.

PowerShell: cari program yang memakai port 80
netstat -ano | findstr :80
Pemecahan masalah

SmartScreen

Karena Localix belum ditandatangani dengan sertifikat berbayar, Windows SmartScreen bisa menampilkan "Windows protected your PC" saat installer dijalankan.

  1. Cocokkan file dengan SHA256SUMS.txt dari halaman rilis.
  2. Di dialog SmartScreen, klik More info.
  3. Klik Run anyway.
PowerShell: hitung checksum
Get-FileHash .\localix.setup.exe
Unduh Localix hanya dari halaman rilis resmi: github.com/kurnya/Localix/releases.
Pemecahan masalah

Update Localix

Unduh installer versi terbaru dan jalankan. Project (www), database (data), dan pengaturan (config) tetap tersimpan, termasuk saat update dari versi 0.1.0.

FAQ

Apakah bisa memakai beberapa versi PHP?

Bisa. PHP 8.4 sudah disertakan, dan 8.2, 8.3, atau 8.5 bisa dipasang dari halaman PHP. Satu versi aktif dalam satu waktu.

Bisakah menjalankan php dan composer dari terminal?

Bisa, setelah mengaktifkan PHP di terminal di halaman PHP.

Apakah Localix memasang service Windows?

Tidak. Apache dan MySQL berjalan sebagai proses yang dikelola Localix, bukan service Windows.

Di mana data database disimpan?

Di data/mysql/ di dalam folder Localix.

Apa password root MySQL?

Kosong (tanpa password). Anda bisa mengaturnya lewat phpMyAdmin.
