Catatan Rilis

Fitur baru, peningkatan, dan perbaikan di setiap versi Localix.

v0.2.0 Terbaru 10 Oktober 2026

Kelola PHP dari aplikasi

Pasang, perbarui, dan ganti versi PHP serta phpMyAdmin langsung dari Localix, dengan tampilan lima halaman yang lebih ringkas.

Baru

  • Halaman PHP: pasang, perbarui, dan ganti PHP 8.2 sampai 8.5 serta phpMyAdmin dari aplikasi. File diunduh dari situs resmi dan diverifikasi SHA-256.
  • Ganti versi PHP dari dasbor atau menu tray; versi sebelumnya dipulihkan otomatis jika Apache gagal start.
  • Atur extension dan pengaturan php.ini dengan centang, plus baris kustom yang diuji sebelum dipakai.
  • Navigasi lebih ringkas: Dashboard, Projects, PHP, Logs, Settings.

Peningkatan

  • Update Localix mempertahankan project (www), database (data), dan pengaturan (config), termasuk dari versi 0.1.0.
  • phpMyAdmin dilayani dari folder runtime-nya, tetap login setelah update, dan hanya bisa dibuka dari localhost / 127.0.0.1.
  • Start, stop, dan restart tiap service langsung dari dasbor; Check Ports kini mendeteksi port yang dipakai aplikasi lain.

Perbaikan

  • Project Laravel baru tidak lagi error HTTP 500 (extension SQLite kini aktif).
  • Log akses Apache kini berisi data request lengkap, tidak hanya kata common.
  • Label status kini mudah dibaca di tema terang.

Rilis perdana

Versi publik pertama Localix: pengelola server lokal yang sederhana untuk Windows, untuk menjalankan Apache, PHP, MySQL, phpMyAdmin, project lokal, dan Virtual Host dari satu aplikasi desktop.

Sorotan

  • Kontrol Apache dan MySQL dengan satu klik.
  • Dasbor desktop untuk status server, port, log, pengaturan, dan shortcut.
  • Halaman localhost modern dengan branding Localix.
  • Pemindaian project langsung dari folder www; daftar Projects dan Virtual Host ikut diperbarui.
  • phpMyAdmin bawaan, pembuat Virtual Host untuk domain lokal, dan pembantu pembuatan project Laravel.
  • Penampil log untuk Localix, Apache, MySQL, dan output runtime lainnya.
  • Tema terang, gelap, dan ikuti sistem.
