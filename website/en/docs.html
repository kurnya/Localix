Getting Started

Introduction

Localix is a local server manager for Windows. Apache, PHP, MySQL, phpMyAdmin, and Composer are included, so you can run local web projects without installing or configuring anything by hand.

Current version: 0.2.0. Download from GitHub Releases. See what's new in the Changelog.

What's included

  • Apache 2.4: web server (default port 80)
  • PHP 8.4: bundled PHP runtime. PHP 8.2, 8.3, and 8.5 can be installed from the PHP page
  • MySQL 9.6: database server (default port 3306)
  • phpMyAdmin 5.2: web-based database manager
  • Composer 2.9: PHP dependency manager
Getting Started

Installation

Two release formats are available:

Installer

A standard Windows setup wizard. You can choose the install folder.

localix.setup.exe

Portable

A single exe, no installation. Data is kept in a localix-data folder next to it.

localix.0.2.0.x64.exe

Steps

  1. Open the latest release on GitHub.
  2. Download localix.setup.exe or the portable build.
  3. (Optional) Check the file against SHA256SUMS.txt.
  4. Run the installer, or open the portable build.
Windows SmartScreen may show a warning because the app is unsigned. See SmartScreen.
Getting Started

First run

  1. Open Localix. The dashboard opens with Apache and MySQL stopped.
  2. Click Start All to start both.
  3. Click Localhost or open http://localhost in your browser. The Localix welcome page means the server is running.
  4. Click phpMyAdmin or open http://localhost/phpmyadmin to manage databases.
  5. Click Folder www and put your projects there.
Default MySQL login: username root, empty password.
Getting Started

Folder structure

After installation, the Localix folder looks like this. The portable build uses the same folders inside localix-data/.

Localix install folder
localix/
├── localix.exe          # Main app
├── resources/runtime/   # Bundled runtimes (read-only)
│   ├── apache/          # Apache 2.4
│   ├── php/8.4/         # PHP 8.4
│   ├── mysql/           # MySQL 9.6
│   ├── phpmyadmin/      # phpMyAdmin
│   └── composer/        # Composer
├── www/                 # ← Put your projects here
├── runtimes/            # PHP / phpMyAdmin installed from the PHP page
├── config/
│   ├── httpd.conf       # Apache config
│   ├── php.ini          # PHP config (managed from the PHP page)
│   ├── my.ini           # MySQL config
│   └── vhosts.conf      # Virtual host config (generated)
├── data/
│   └── mysql/           # MySQL data
└── logs/                # Localix, Apache, MySQL, and PHP logs
Features

Projects

Every folder inside www/ is treated as a project. Localix scans this folder while it runs and lists each project on the Projects page with its URL and folder.

URL pattern
www/my-project   →  http://localhost/my-project/
www/portfolio    →  http://localhost/portfolio/
Laravel projects with a public/ folder are served from public/ automatically. The folder name phpmyadmin is reserved and ignored by the scanner.
Features

Virtual Host

Virtual Hosts give each project its own local domain, such as my-project.locx, instead of localhost/my-project.

  1. Open the Projects page.
  2. Turn on Virtual host.
  3. Set the domain suffix (default .locx) and click Simpan.
  4. Click Copy hosts entry (or Buka hosts file) and paste the entries into the Windows hosts file.
  5. If a new project's domain is missing, click Regenerate.
C:\Windows\System32\drivers\etc\hosts
127.0.0.1  my-project.locx
127.0.0.1  portfolio.locx
Editing the hosts file needs Administrator rights. Open Notepad with Run as administrator before pasting the entries.
Features

Laravel

Composer is included, so you can create Laravel projects without installing PHP or Composer on Windows.

  1. On the Projects page, click + Laravel.
  2. Fill in Nama project Laravel (project name) and pick the Lokasi (location) with Browse.
  3. Click Buat project. Localix runs composer create-project laravel/laravel with its bundled PHP and Composer.
  4. When it finishes, the project appears on the Projects page (with a .locx domain if Virtual Hosts is on).
Laravel's default .env database settings match Localix: DB_HOST=127.0.0.1, DB_PORT=3306, DB_USERNAME=root, DB_PASSWORD= (empty).
Features

PHP

Everything PHP lives on the PHP page, which has three tabs.

Versions (Versi)

Install, update, activate, or remove PHP 8.2 to 8.5. Files come from the official PHP site and are checked with SHA-256 before use. Click Periksa update to check for newer versions. You can also switch the active version from the dashboard or the tray menu. If Apache fails to start after a switch, the previous version is restored.

Extensions

Tick the extensions you want enabled. Enabled by default:

  • pdo_mysql, mysqli, pdo_sqlite, sqlite3 for databases
  • openssl, curl for secure connections
  • gd, mbstring, zip, fileinfo, intl for web frameworks

mysqli, mbstring, openssl, and pdo_sqlite are always on and cannot be turned off.

Settings (Pengaturan)

Set memory limit, upload size, max execution time, timezone, showing errors in the browser, and OPcache, then click Simpan & terapkan. Localix tests the new config/php.ini before applying it. Extra lines go in Custom directives. Use Lihat php.ini to view the result or Kembalikan default to start over.

Features

phpMyAdmin

phpMyAdmin is pre-installed. Open it with the phpMyAdmin button on the dashboard or at http://localhost/phpmyadmin, then log in with username root and an empty password.

For safety, phpMyAdmin only opens from your own computer (localhost / 127.0.0.1). Newer versions can be installed from the Versi tab on the PHP page.

Features

Logs

The Logs page shows the Localix, Apache Error, Apache Access, MySQL, and PHP Error logs. Use Refresh to reload, Clear Log to empty a log, and Open Logs Folder to open the logs/ folder.

Configuration

Settings

  • Run at Windows startup: Localix starts in the background (system tray) when Windows starts.
  • Start services on open: Apache and MySQL start when Localix opens, and the browser can open automatically once the server is up.
  • Theme: light, dark, or follow Windows.
  • Ports: change the Apache (default 80) and MySQL (default 3306) ports.
  • Maintenance: Check Ports, repair the phpMyAdmin config, and reinitialize MySQL data (the old data is backed up first).
Configuration

Apache

Apache's configuration lives in config/httpd.conf. You can edit it to enable modules or adjust folder access.

A broken config can stop Apache from starting. If that happens, undo your change and check the Apache Error log on the Logs page.
Configuration

MySQL

MySQL is configured through config/my.ini, and its data is stored in data/mysql/. The default port is 3306; change it in Settings if another database server already uses it.

To back up, stop MySQL and copy the data/mysql/ folder, or export your databases from phpMyAdmin.
Troubleshooting

Port conflicts

If Apache fails to start, port 80 is usually taken by another app (IIS, Skype, XAMPP, and so on). Click Check Ports in Settings to see which ports are in use.

Option A: close the other app

Stop the app that uses the port, then click Start All again.

Option B: change the Apache port

  1. Open Settings.
  2. Change the Apache port to a free one, such as 8080.
  3. Restart Apache, then open http://localhost:8080.

Option C: run as Administrator

Right-click Localix and choose Run as administrator. This can help when Windows refuses access to port 80.

PowerShell: find what is using port 80
netstat -ano | findstr :80
Troubleshooting

SmartScreen

Because Localix is not signed with a paid certificate yet, Windows SmartScreen may show "Windows protected your PC" when you run the installer.

  1. Check the file against SHA256SUMS.txt from the release page.
  2. In the SmartScreen dialog, click More info.
  3. Click Run anyway.
PowerShell: compute the checksum
Get-FileHash .\localix.setup.exe
Only download Localix from the official release page: github.com/kurnya/Localix/releases.
Troubleshooting

Updating Localix

Download the latest installer and run it. Your projects (www), databases (data), and settings (config) are kept, including when updating from 0.1.0.

Troubleshooting

FAQ

Can I use multiple PHP versions?

Yes. PHP 8.4 is included, and 8.2, 8.3, or 8.5 can be installed from the PHP page. One version is active at a time.

Does Localix install Windows services?

No. Apache and MySQL run as processes managed by Localix, not as Windows services.

Where are database files stored?

In data/mysql/ inside the Localix folder.

What is the MySQL root password?

It's empty (no password). You can set one in phpMyAdmin.
