v0.2.0 Latest 10 October 2026

Manage PHP in-app

Install, update, and switch PHP and phpMyAdmin from inside Localix, with a simpler five-page layout.

New

  • PHP page: install, update, and switch PHP 8.2 to 8.5 and phpMyAdmin from inside the app. Files come from the official sites and are verified with SHA-256.
  • Switch PHP from the dashboard or the tray menu; the previous version is restored if Apache fails to start.
  • Configure extensions and php.ini settings with checkboxes, plus custom directives that are tested before they are applied.
  • Simpler navigation: Dashboard, Projects, PHP, Logs, Settings.

Improvements

  • Updating keeps your projects (www), databases (data), and settings (config), including when updating from 0.1.0.
  • phpMyAdmin is served from its runtime folder, keeps the login across updates, and only opens on localhost / 127.0.0.1.
  • Per-service start, stop, and restart on the dashboard; Check Ports detects ports used by other applications.

Fixes

  • New Laravel projects no longer return HTTP 500 (SQLite extensions are now enabled).
  • The Apache access log now records full requests instead of only the word common.
  • Status badges are now easy to read in the light theme.

v0.1.0 7 June 2026

Initial release

The first public release of Localix: a simple local server manager for Windows that runs Apache, PHP, MySQL, phpMyAdmin, local projects, and Virtual Hosts from one desktop app.

Highlights

  • One-click service control for Apache and MySQL.
  • Desktop dashboard for server status, ports, logs, settings, and shortcuts.
  • Modern localhost landing page with Localix branding.
  • Live project scanning from the www folder; the Projects and Virtual Host lists update while Localix runs.
  • Bundled phpMyAdmin, a Virtual Host generator for local domains, and a Laravel project creation helper.
  • Log viewer for Localix, Apache, MySQL, and related runtime output.
  • Light, dark, and system theme support.
