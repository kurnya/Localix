v0.1.0 Terbaru
June 2025

Rilis Awal

Introducing the first public release of Localix - a lightweight, service-free local development stack for Windows web developers.

Fitur Inti
  • Bundled Apache 2.4, PHP 8.4, and MySQL 8.x.
  • Clean desktop interface to start and stop services.
  • Automatic project scanning inside the www folder.
  • Virtual host generator with custom .locx support.
  • Built-in Laravel template generator and composer.
  • Available as installer and portable bundle.
Peningkatan
  • Optimized startup times for MySQL.
  • Reduced download package size.
  • Sync system appearance for dark and light theme.
Perbaikan
  • Fixed Apache port 80 collisions with IIS.
  • Fixed permissions writing to hosts file on some restricted setups.
