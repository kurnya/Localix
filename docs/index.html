Mengapa Localix

Semua yang Anda butuhkan, tanpa ribet

Dibuat untuk pengembang yang menginginkan server lokal yang cepat dan bersih tanpa beban berlebih.

Mulai dengan Satu Klik

Jalankan atau hentikan Apache, PHP, dan MySQL bersama-sama atau secara terpisah dari satu panel kontrol.

Pemindai Proyek Langsung

Masukkan folder ke dalam www dan Localix akan mendeteksinya secara otomatis. Tanpa perlu konfigurasi manual.

Host Virtual

Petakan proyek Anda ke domain .locx yang cantik seperti myapp.locx dalam hitungan detik.

Pembantu Laravel

Buat proyek Laravel baru langsung di dalam Localix menggunakan Composer dengan sekali klik.

Tanpa Layanan Sistem

MySQL berjalan sebagai proses terkelola di dalam Localix. Tidak ada polusi layanan Windows, uninstal bersih.

Tema Terang / Gelap

Mendukung tema terang, gelap, dan sistem. Nyaman di mata untuk sesi pengembangan yang panjang.

Memulai Cepat

Aktif dan berjalan dalam 4 langkah

Dari pengunduhan hingga localhost dalam waktu kurang dari dua menit.

1

Unduh

Ambil localix.setup.exe atau versi portable dari GitHub Releases.

2

Pasang

Jalankan installer. Tidak memerlukan runtime atau dependensi tambahan.

3

Mulai

Klik Start All di dasbor. Apache dan MySQL langsung aktif seketika.

4

Bangun

Tempatkan proyek Anda di www/ dan buka localhost/proyekanda di peramban.

FAQ

Pertanyaan Umum

Ya, sepenuhnya gratis. Tanpa langganan, tanpa fitur premium, tanpa kunci lisensi. Unduh, instal, dan gunakan selamanya tanpa biaya.
Tidak ada layanan sistem global yang diinstal. Apache dan MySQL berjalan sebagai proses yang dikelola oleh Localix yang berada di dalam folder aplikasi. Menghapus instalasi akan membersihkan semuanya.
Windows 10 dan Windows 11 (64-bit) didukung. Tersedia versi installer maupun portable.
Anda dapat menjalankan Localix sebagai Administrator, atau mengubah port Apache di panel Pengaturan ke port lain yang tersedia seperti 8080.
Rilis saat ini dilengkapi dengan PHP 8.4. Peralihan multi-versi direncanakan untuk rilis mendatang.
Aplikasi saat ini didistribusikan tanpa tanda tangan digital (unsigned). SmartScreen memperingatkan tentang penerbit baru. Anda dapat memverifikasi unduhan menggunakan file SHA256SUMS.txt di halaman rilis.
